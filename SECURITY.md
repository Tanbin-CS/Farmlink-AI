# Security policy

This is a competition sandbox. It does not process real money, identities, or credentials.

- Please report vulnerabilities privately to the repository owner through GitHub (Security → Report a vulnerability) rather than in public issues.
- Never commit secrets. Provider keys and database URLs belong in the hosting provider's secret settings only. `VITE_*` variables are public.
- The full self-assessment is in [docs/SECURITY_ASSESSMENT.md](docs/SECURITY_ASSESSMENT.md).
